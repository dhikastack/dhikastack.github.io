Authentix

A static landing page concept designed to help thrift shoppers learn how to identify authentic branded products and shop second-hand items with more confidence.

  • My roleAI-assisted frontend implementation
  • TypeIndividual project
  • Period2025
  • Built withHTML · CSS

Overview

The landing page presents Authentix as a concept for thrift shoppers, with sections covering product authenticity, brand details and safe thrifting tips. I built the page myself as front-end practice, with AI assistance during implementation.

Sections on the page

  • QR and barcode verification concept.
  • Authenticity education.
  • Safe thrifting tips.

Scope

This project explores the visual design and presentation of an authenticity-checking concept. The features shown on the page are conceptual and are not functional: there is no scanner, no database and no back end behind them.

What it practised

Page structure in semantic HTML, layout and type in hand-written CSS, and a single-page composition with a hero, a feature section and a footer.
