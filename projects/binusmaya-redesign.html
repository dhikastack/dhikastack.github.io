BINUSMAYA Redesign

A redesign focused on improving the notification experience in the BINUSMAYA platform.

  • My roleHigh-Fidelity UI Designer
  • TypeTeam academic project
  • Period2025
  • ToolsFigma

Overview

I contributed as a UI/UX Designer by adding a new feature to sort the notification list and designing a clearer, more organised experience around it.

The feature

The redesigned notification screen introduces a category filter so a student can narrow a long, mixed list down to the notifications they are actually looking for. The prototype covers these categories:

  • Class
  • Thread
  • Beelingua
  • Others

The prototype also handles the empty case, showing a clear message when a selected category has nothing in it.

My contribution

High-fidelity UI design for the redesigned notification list and its filter.
